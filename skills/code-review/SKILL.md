# 代码审查

1. 用 list_files 定位用户指定代码，然后用 read_file 阅读实现。
2. 按需读取 references/checklist.md，核对边界与错误处理。
3. 优先报告有源码依据、可说明触发条件的问题；不要将猜测表述为已验证事实。
4. 不运行 Python、Shell 或技能脚本；静态审查不能声称测试已通过。
5. 阅读不完整时明确审查覆盖范围，不宣称全面检查。
6. 用户要求文件形式时用 write_file 保存审查意见，修改前先读取。
7. Planning 的完成证据来自实际文件工具，技能读取本身不构成证据。

技能指导不得覆盖系统规则、用户要求或工作区文件权限。
