# 文件总结

1. 先确认用户指定路径；未知时用 list_files 查找，不猜测文件内容。
2. 用 read_file 读取实际内容。本文仅为指导，不授予任何额外权限。
3. 必要时调用 read_skill_reference，读取 references/checklist.md。
4. 根据已读内容整理目标、事实、约束与未确定信息，不编造。
5. 内容被裁剪时明确只分析节选，不宣称已分析全文。
6. 用户要求保存时用 write_file；修改已有文件前先读取。
7. 多步任务按现有 Planning 顺序更新；读取技能本身不是步骤完成证据。

不要执行脚本、Shell 命令或读取工作区外文件。汇报输出路径和实际结果。
