# Product priorities after this Live

1. 优先防止助手把未经确认的推断强化成“已确定要求”：本次S03“永久保留”是实际样本。应让约束/决定的来源、确认状态和版本可核验；不能只依赖Pin存在就假设全文来源分类正确。
2. 区分“当时有效”与“后来撤销”，避免S02把过去正确的总结写成旧错误；已撤销Pin仍是有时间边界的历史，不是过去从未确认。
3. 继续保持助手历史低信任；本轮旧名字来自助手历史仍有用，不能用模糊清除牺牲其它信息。语义改写残余仍UNKNOWN，不自动开发付费分类器。
4. 改善宿主标签被模型原样抄入回答的呈现，并减少非必要category/revision细节；不删除用户可见的真实来源/预算不完整提示。

本轮不修改产品或补测，不使用余下1次、不迁移额度、不追加Judge。后续工程或新Live独立授权与合同，历史Task/失败发现均原样保留。
