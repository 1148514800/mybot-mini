# Remaining risks

- Live尚未授权：真实Tool Call生成、Provider下一步是否包含有用行为、短T02窗口、取消Usage与关闭仍UNKNOWN。
- SDK观察器能证明精确消息包含/HTTP发送/响应，不能证明远端语义理解；最终Semantic Adherence须独立审阅，字符串形状检查不是通用评审器。
- 模型可能直接答复或无下一工具，不能通过额外提示/工具注入制造前提；晚到Steer只能记INCONCLUSIVE，不补跑。
- 首块若已为终态，不能人为制造操作窗口。屏障延迟是测试控制，不是部署性能。
- 固定Case预算可能阻止fallback或复杂工具链；安全拒绝是边界，不是理由扩大额度。
- 关闭依赖协程协作，不能对忽略取消的第三方提供强制OS退出保证；无法确认时保留不确定状态并停止。
- 共享Git AppleDouble旁索引警告不自动代表正式pack坏；只读核对，不擅自删除对象。
