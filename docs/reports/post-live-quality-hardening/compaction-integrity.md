# 精确引用、部分保留与有界覆盖

继续使用exact-citation-v1：九字段数组、turn/message/quote协议均不变，无配置迁移或持久化摘要迁移。新旧有效v1文档兼容；仍拒绝重复键、无效结构、工具摘要调用、超时、取消、失败工具被归为完成、越权角色来源。语义压缩默认关闭并要求显式成本授权。未引入宽松相似度、模型释义或新索引协议。

所有有界条目先逐条验证，再决定能否应用。引用必须同时属于发给模型的来源节选和脱敏原始来源，不能把节选标记或拼接边界当原文。诊断仅公开有效/无效/删除数量、原因类别和字段覆盖，不公开引用正文、参数、Receipt、nonce或私有响应。

若目标、用户约束或completed_work条目不合法，整份fallback；关键权限/完成证据不能被静默删除。非关键单条失效时，只有存在合法目标或用户约束锚点，才允许保留其他独立验证的引用，状态semantic_applied_partial。没有合法锚点或全部失效仍fallback。无效引用绝不进入最终摘要，不重试模型。缓存命中仍保留partial标签和诊断，不能冒充完整有效。

裁剪保留全部已选目标/约束；已选decisions、pending_work、unresolved_issues、uncertainty各保留至少一条。先移除冗余条目与非关键字段，再按时间去除较早冗余，不能删光重要类别来凑空间。无法容纳覆盖下限时fallback。类别下限只覆盖模型实际选择的有效证据，不证明所有历史事实都被选中；history_information_incomplete和coverage=unverified始终提示摘录可能遗漏，原Session不改写。

摘要输入先脱敏，再从每消息最多1024字符逐级缩至64字符的首尾节选；不缩当前用户消息、系统规则或当前工具协议。每轮重算完整摘要请求的UTF-8保守估算、原input_tokens及当前有效供应商TokenCounter.enforce。JSON用紧凑分隔符；仍放不下则明确fallback_input_limit/token_budget且零发送，不抬高窗口或主备参数。字符上限只是来源节选限制，不冒充精确供应商Token。

原独立摘要超时、取消传播、每回合max_calls、Controller为主任务保留请求、主备Provider及物理记账均沿用。新设备巡检合成场景验证规则变更、未知、待部署和失败类别；不使用历史T03答案。剩余局限：节选可能切掉中间事实，模型可能漏选或误分类，覆盖下限不是语义完整性的证明；新策略可能更保守地fallback。
