# 剩余风险

- stop仅确认供应商结束协议，不证明回答在语义上覆盖全部要求；新提示无法保证固定输出Token下内容完整。没有自动续请求，后续由用户选择。
- v1仍由模型选择精确引用，可能漏选、错误分类或遗漏中间来源。覆盖下限保护已选类别，不证明每个历史决定和未知都保留；空间不足仍fallback，原Session是事实来源。
- partial允许保留独立有效的非关键子集，复杂边界仍可能使更多摘要回退。关键目标/约束失效或伪完成证据仍整份拒绝。旧合法v1协议无需迁移；未引入模糊匹配。
- 动态缩减可能丢失来源中段信息，也可能使原来未发送的摘要现在合法发送；该调用仍计入原预算，并非免费优化或请求数必然下降。所有生产默认语义压缩仍关闭。
- Coding合同检查是紧凑模型指令与信息传递机制，没有新增自动证明器。合成Client预定读取/修改行为不代表真实DeepSeek会识别边界；verified仍仅表示当前Revision通过指定测试。
- 缺失finish_reason的旧进程内工具调用为兼容仍经原权限/审批执行，但不确立完整文本回复；未知结束文本明确未确认。协议异常可能使不规范第三方Client更保守地结束。
- 没有新命令权限、网络权限或Receipt恢复通道。部分输出可能含用户任务正文，仅在聊天原有脱敏路径显示；活动统计不包含完整私有响应或原始工具参数。

历史Live失败未改判；本轮不能声明真实任务成功率或费用已改善。未来真实质量验证必须另行预注册、冻结、授权，不使用旧剩余9次额度。
