# 剩余技术债

P0 已确认缺陷0，已确认 P1/P2 缺陷本轮闭合，但这不等于所有风险消失。剩余8项：

- P1 D14：实际网关与官方 Tokenizer/template/window 的映射不可确认。strict 不可用于正常请求；estimate 不提供精确窗口保证。
- P1 D15：legacy 基础文件工具路径检查存在TOCTOU潜在风险，尚未做攻击复现。不要把合作锁当恶意进程隔离。后续应采用已验证的 descriptor 相对 IO，保持 Coding 工具权限不变。
- P1 D16：不同workspace共用一个Session路径不受本次锁保护，明确只支持单写者；后续单独设计存储锁与冲突恢复。
- P1 D18：真实摘要质量、供应商错误/Usage及实际费用未验证。摘要始终不能恢复权限或验证结论。
- P2 D17：Web内存历史与容量限制是产品约束；可选持久化应另设安全恢复协议。
- P2 D19：部分同步IO在慢设备上可能延迟取消；没有硬实时承诺。
- P2 D20：包含双下划线的特殊MCP短名称检索质量需专门用例，不能据此更改冻结评分。
- P2 D21：共享脱敏逻辑暂位于web.security，层次依赖可后续局部整理。

不以增加模型额度、弱化审批、重放工具、修改Benchmark评分来“消除”这些事项。所有旧Phase文档与历史raw保持原样；此报告记录当前能力边界。
