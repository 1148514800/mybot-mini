# 剩余限制

1. SQLite和外部文件/命令/远程服务没有跨域原子提交。started到finished之间可能已经发生副作用；恢复使用execution_uncertain和人工检查，不能自动撤销或重放。
2. PID重用/无权限检查会保守保留running。复核不替用户调查残留进程；原WorkspaceLease仍不可绕过。多进程写日志可靠不等于分布式执行协调。
3. 数据库明文，权限和脱敏不能防同UID恶意程序、未知格式秘密、备份/快照或底层介质残留；canonical hash不是防篡改签名。私有路径检查与SQLite打开之间仍存在同UID竞争风险。
4. 恢复的是安全聊天，非完整可重放模型请求；不恢复工具正文、Plan、TaskContract、verified、Receipt或nonce。前次真实工具资料可能需要新请求重新读取。
5. Pin有数量/字节/历史与真实预算上限，可能明确省略；六轮以外持久文本可查，不自动全量进模型。并列Pin只提示待确认，不自动做语义冲突消解。
6. 撤销/替换按精确文本省略整个相关历史轮次，可能丢无关信息；不识别所有语义改写，也不删除当前用户主动再输入的文字，不是强制语义遗忘。
7. 私有POSIX权限可能在ExFAT不可用，须选用户目录/APFS；没有透明降级。主DB限额不包含日志/备份额外空间；满库安全停止，暂无自动轮换或迁移。
8. Web是本地单用户，不是公网多租户；每次展示64消息、20会话、128活动事件；更早消息显式翻页。CLI legacy_json保持旧近期快照语义，Pin不随JSON跨重启。
9. 未做真实API/真实语义摘要/付费Judge或真实长期任务能力比较；实际成功率、模型如何遵循Pin与费用变化仍需独立明确授权的Live验证。
