# Remaining risks

- 没有语义分类器：旧助手的隐含指代、改写、否定、跨句建议无法可靠识别；保留时仅标为历史、非权威和未验证。真实模型是否遵从仍需独立Live。
- 精确原句命中可能保守省略整条助手回复；其中其他有用建议也会丢失，诊断必须保持。没有承诺所有历史语义零损失。
- 旧JSON/第三方手动restore没有可信ID，截断、脱敏或源正文不一致时会保守省略。完整协议组无法细分时，同轮用户事实仍可能损失。
- 预算仍可正常摘要或省略独立事实；source-preservation的5/5只适用于可验证纯文本来源、独立单元及充足预算。
- 当前host生命周期/标签是参考信息，不能消除未知部署的模型行为风险。未知tokenizer/provider window不被本轮推测。
- 同类Pin只标为unassessed，没有开发语义冲突检测或自动失效处理。用户仍需显式替换/撤销。
- 本轮不修复旧prepare verify硬编码real_requests=0；原Live冻结适配器、账本及报告不动。

旧冻结observer的information_loss按整轮对象相等判定，局部遮蔽后会把保留片段误计为来源丢失。本轮保留observer源码；旧预算离线E2E保留3/5基线并强化实际请求5/5断言。后续新Live合同需采用来源片段/实际单元指标，不能直接使用旧observer数字，也不能重跑旧批次。
