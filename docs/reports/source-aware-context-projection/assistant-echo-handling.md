# Assistant echo handling

有失效Pin时，历史助手纯文本若精确包含其完整原句，保守省略这条助手内容，并以明确的宿主“助手文本已省略”占位说明替代；不伪造工具返回。记录omitted_assistant_messages，原用户独立片段保留。此包含检查只用于助手/协议风险，不用于确定user来源，不做模糊匹配或全局用户文本替换。

其他历史助手内容添加低信任、非用户确认、非当前规则、不可恢复失效Pin的标签；语义改写明确unverified。没有可靠来源映射的“文件名字仍是之前那个”等改写可能继续保留，不能声称已经清除。标签和生命周期参考提供可信来源等级，不能保证任何真实模型一定遵守。

助手的建议即使位于摘要decisions/confirmed_facts字段，仍附source_role/evidence_status及非用户确认警告；摘要引用校验保持严格。它不能凭助手复述将撤销Pin复活、将建议升格为确认或恢复审批。精确包含检查可能保守损失整条助手中的独立建议，明确计入省略统计，不以用户来源保留5/5掩盖这类损失。

若存在工具协议且命中失效来源或风险原句，整个协议轮组省略；不能只删除助手tool_calls而保留工具结果。
