# Trust boundary

唯一新增数据是宿主提交边界索引；决定视图和分类提议均只读/不持久化。Pin仍只能经已有CLI confirm或带Cookie/Origin/CSRF校验的Web确认操作写入。没有新增模型工具、命令权限、MCP能力或自动确认通道。

用户普通原文→归属校验，用户真实固定动作→精确原文确认，模型输出→普通助手消息。这三条路径独立。TaskContract是本轮执行证据管理，不会成为持久决定来源；恢复聊天与时间线也不会恢复旧审批、Receipt、nonce或Controller verified。

Web新增decisions只在已有认证状态GET返回，范围限当前会话已固定的来源短句及有界元数据；不把原始决定内容追加到SSE资源事件。普通Pin面板提示模型回答不是宿主确认，详情解释来源和生效顺序；不输出整份用户历史、私有工具数据或凭证。

非目标：防恶意同UID直接改SQLite、通用语义蕴含判断、任意自然语言可选/未决自动分类、清除全部助手语义影响、保证LLM不泄漏内部标签。模型自由文本可以依然错误；其内容没有进入可信集合，不等于错误已被自动识别或改写。
