# Remaining risks

1. 自由文本仍可能把禁止自动删除强化成永久保留、把可选说成强制，或对过去正确结论说“更正”。本轮只隔离可信视图，未实现通用语义正确性检测/实时改写。
2. 助手历史的语义影响仍UNKNOWN。确定性精确引用和失效来源遮蔽不证明所有改写、暗示、因果影响已清除。
3. 新上下文说明及UI减少内部字段负担，但category/revision等兼容元数据仍保留在模型参考中；没有真实LLM验证其不再复述标签。
4. 旧v1库没有提交日志，迁移前历史精确边界不可恢复。必须接受null/unknown，不能用revision、墙钟或相邻事件猜测。DB v2不支持老程序直接降级读取；升级时需停止同库旧写者，不能与不维护新提交索引的旧版本同时写同一库。
5. 有界上下文仍可能按预算遗漏历史；来源可核验不等于上下文完整、模型遵从或任务正确。失效Pin正文不重新注入模型，详细历史名称需要宿主视图查询。
6. 同UID恶意数据库/文件系统篡改、SQLite底层持久化保证仍沿用原边界。提交元数据不是单独签名的防篡改审计系统。

本轮没有使用真实DeepSeek验证语义遵从、标签抄写概率或模型对时序的自然表达；不能宣布所有真实模型语义缺陷已解决。
