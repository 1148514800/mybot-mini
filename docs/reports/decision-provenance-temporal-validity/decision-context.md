# Decision context and budget

SessionHistory.context_turns仍先做Source-Aware跨度投影，再交给ContextManager。只将source_verified的当前Pin交给原Pin渲染器；撤销来源仍精确遮蔽，独立事实保留，工具组继续原子处理。没有改原用户消息或持久化助手文本。

生命周期参考保留原user角色与JSON外壳，兼容原离线预算观察器、原Pin标签和所有旧断言。policy改为自然语言：精确原文不授权更强改写；可选/未决不得自行升级；过去有效不因后来失效而追溯纠错；普通回答不应复述内部分类与修订号。助手历史前缀缩短为自然语言说明。没有System级新权限，也没有输出过滤器或语义黑名单。

参考含当前分类集合/确认提交顺序、最多12条失效Pin来源元数据、确认事件和生效/失效提交序号；显式报告历史遗漏与旧库边界未知。为保持原Source-Aware撤销保护，不把失效Pin正文重新注入模型。历史名称可能仍见于低信任助手历史；宿主UI/CLI可查精确历史原文，模型参考不保证复原所有过去名称。

实际最终浏览器12次合成请求，其中10次带生命周期参考。以相同Pin元数据对照旧参考：新参考单独估算1690–1769 Token，旧参考1173–1211，增量517–558。方法为JSON UTF-8字节+256框架+每消息32，含独立框架费用；不是供应商Tokenizer或账单。活跃Pin原文、工具schema和其它上下文另由原完整请求预算计入。这是样本测量，不是所有100-Pin情况的固定开销。

所有参考仍经过ContextManager保护输入预算、TokenCounter和输出预留；预算不足拒绝或原规则省略，不扩窗、不隐式调用模型。新增专项验证256估算Token下保护参考失败关闭、实际请求输出预留不变。v1不保证模型遵守这些说明、不保证不抄标签；需要另行授权的新Live验证。
