# Root cause analysis

原始发现仅引用旧Live公开报告，未读取其私有SQLite、Prompt或旧响应文件；旧Task评分与Decision Classification FAIL原样保留。

S03的“禁止自动删除原始笔记”可以被精确归属到用户，但模型把它强化为“原始笔记永久保留”。来源真实性与语义蕴含是两种不同证据。旧实现只有Pin原文和助手自由文本，没有独立、可查询的决定证据视图；回答中的“已确定”措辞本身没有确认权威。

S02的旧命名确实在替换之前有效。只有当前active/revoked/superseded投影和revision不足以回答“当时是否有效”；当前撤销状态不能追溯为过去错误。旧数据库还没有保存append_many的提交区间，不能把相邻事件天然当作两个已提交状态。

历史助手语义复述仍是可见影响通道。精确字符串省略不是语义清洗；新实现不把这条通道升级为用户证据，也不声称已经消除其因果影响。旧内部标签被复述是呈现缺陷，新参考采用自然语言边界说明，UI隐藏无关修订字段，实际模型是否减少抄标签尚未Live验证。
