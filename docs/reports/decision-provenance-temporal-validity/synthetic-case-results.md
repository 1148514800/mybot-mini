# Synthetic case results

全部Fixture重新使用公开设计短句构造，未使用旧私有SQLite。新增专项56项：来源20、时间线20、上下文16。全量计数包含专项一次，定向重复执行不重复计入。

|场景|机制结果|证据与边界|
|---|---|---|
|A 推断强化|PASS|SyntheticClient原样返回“原始笔记永久保留是已确定要求。”，助手回复和消息角色保持；可信原文集合仍只有本地处理/禁止自动删除两条，Pin数2，没有新增永久保留。没有声称自动检测该句的全部语义。|
|B 历史有效|PASS|旧名、新名、撤销三边界有效集合分别旧/新/空；旧项仍可在旧提交边界查询为active，替换内部事件序号拒绝。|
|C 可选与未决|PASS|CLI可选、全文搜索未决及助手缓存建议不产生任何自动决定；原文归属仍未作语义分类。显式固定open_question只确认原文用途。|
|D 长对话恢复|PASS|离线超过六轮并重新打开SQLite后Pin、时间线一致；实际合成请求含早期两约束，旧执行证据未恢复。Chrome同样跨七轮并真正停止/启动服务验证。|
|E 工具协议|PASS|合法assistant Tool Call/tool Result配对在投影后仍有效；原Source-Aware协议回退及工具权限测试保留。|
